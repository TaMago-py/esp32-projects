### rgb_light_video

Here I made the ___rgb___ go through the __chromatic circle__. For this, I made an __array__ with the __values__ for every color.

If a color reaches a value of 255, it starts to __decrease__ while the next number __increases__. 

This way, it goes from __red__ to __green__, from __green__ to __blue__ and from __blue__ to __red__.
